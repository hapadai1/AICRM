# AICRM 전체 테스트 실행 방안

작성 2026-07-31. 테스트 항목의 상세 내용은 [전체메뉴_테스트_방법.md](전체메뉴_테스트_방법.md).
스킬·CI 등록 없이 **아래 파일을 열어 명령 그대로 실행**하면 된다.

## 0. 사전 준비 (한 번만 확인)

| 항목 | 확인 방법 |
|---|---|
| PostgreSQL 기동 + `aicrm_dev`·`aicrm_test` DB | `psql postgresql://aicrm:aicrm@localhost:5432/aicrm_dev -c 'select 1'` |
| 백엔드 개발 서버 (:3000) | `curl http://localhost:3000/api/v1/health` → 200. 안 떠 있으면 `cd backend && npm run start:dev` |
| 프런트 개발 서버 (:5173) | 브라우저에서 http://localhost:5173 열림. 안 떠 있으면 `cd frontend && npm run dev` |
| 크롬 설치(웹 테스트용) | `/Applications/Google Chrome.app` 존재 (macOS) |
| 로그인 계정 | `admin / admin1234!` (시드) |

## 1. 백엔드 전체 테스트 — 360건+ (가장 먼저)

서버를 띄울 필요 없다. `aicrm_test` DB에 마이그레이션·시드를 자동 적용하고 API 레벨로 전 도메인을 검증한다.

```bash
cd backend
npm test
```

- 기대 결과: `Test Suites: 18 passed · Tests: 360 passed` (2026-07-31 기준. 이후 늘어날 수 있음)
- 특정 영역만: `npm test -- ../test/backend/contracts.spec.ts` (파일명 교체)
- 베스트 전 단계 시나리오만: `npm test -- ../test/backend/vest-e2e.spec.ts` (13건 — 계약→컨설팅→서명→완료→주문→수정하기 각 단계에서 베스트 넣고 빼기)

## 2. 웹 전 메뉴 테스트 — 실제 브라우저 25단계

**실행 파일: `test/web/all-menus-test.mjs`** — headless 크롬으로 로그인 후 전 메뉴(대시보드~고객 모드)를 열고 대표 조작을 한다. 파괴적 조작(저장·발송·상태변경)은 하지 않는다.

```bash
# 사전: 백엔드·프런트 개발 서버가 떠 있어야 한다 (0번 표)
cd test/web
npm install        # 최초 1회만 (playwright-core)
node all-menus-test.mjs
```

- 기대 결과: 콘솔에 단계별 `PASS/FAIL/SKIP` 표 + `실패 0`
- 스크린샷: `docs/test/screenshots/menus/` (매 실행 시 덮어씀 — 눈으로 훑어볼 것)
- 상세 계약·주문·채촌·작업지시서 대상 데이터는 API로 자동 확보한다. 데모 데이터가 없으면 해당 단계만 SKIP으로 표시된다 (시드: `cd backend && npm run seed:demo && npm run seed:more`)

## 3. 웹 베스트(3피스) 시나리오 — 실제 버튼 클릭

**실행 파일: `test/web/vest-web-test.mjs`** — 계약서 작성 → [베스트 제외] 해제(베스트 행·단가) → 임시저장 → 스타일 컨설팅 → 베스트 [옵션 선택 안함] 제외 → 합계 차감 확인.

```bash
cd test/web
node vest-web-test.mjs
```

- 기대 결과: 마지막 로그 `합계 표시: 합계 1,000,000원` + `DONE — 전 단계 통과`
- 스크린샷: `docs/test/screenshots/vest/` (11장)
- 테스트가 만든 초안 계약은 끝나면 **자동 삭제**된다 (실패 시 로그의 계약번호로 계약 목록에서 [계약 삭제])
- 기본 고객은 `강태오`(신체정보 채워진 시드 고객). 다른 고객으로 돌리려면: `AICRM_CUSTOMER=홍길동 node vest-web-test.mjs`

## 권장 실행 순서 (개발 후 회귀 점검)

1. `cd backend && npm test` — 백엔드 360건
2. `npx tsc --noEmit` (backend·frontend)
3. 서버 2개 기동 확인 → `cd test/web && node all-menus-test.mjs`
4. `node vest-web-test.mjs`
5. 스크린샷 폴더 육안 확인 + [전체메뉴_테스트_방법.md](전체메뉴_테스트_방법.md)의 **[수동]** 항목 중 이번 변경과 관련된 것만 직접 확인

## 문제가 생기면

| 증상 | 원인·조치 |
|---|---|
| 웹 테스트가 로그인에서 멈춤 | 프런트(:5173) 또는 백엔드(:3000) 미기동 → 0번 표 |
| `API 로그인 실패` | admin 비밀번호 변경됨 → `AICRM_PASSWORD=... node all-menus-test.mjs` |
| 단계 SKIP 다수 | 데모 데이터 없음 → `cd backend && npm run seed:demo && npm run seed:more` |
| `browserType.launch` 오류 | 크롬 미설치 또는 경로 다름 → Chrome 설치 |
| 백엔드 테스트가 DB 오류 | `aicrm_test` DB 없음 → `createdb`로 생성 (테스트가 마이그레이션·시드는 자동) |
| 콘솔 404 1건씩 | `/favicon.ico` 없음 — 무해. 파비콘 추가 시 사라짐 |
