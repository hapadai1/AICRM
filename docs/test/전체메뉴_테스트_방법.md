## 5. 계약 관리 (`/contracts`) — 상태 흐름 포함

상태: 작성중(DRAFT) → 서명완료(SIGNED) → 계약완료(COMPLETED) / 취소(CANCELLED). 규칙은 0731 정본 문서.

| 절차 | 기대 결과 | 커버 |
|---|---|---|
| 목록 필터(상태·기간·구분)·검색(q: 전화·구분명) | 필터·합계 요약 정합 | [자동-API] contracts.spec |
| 완료 계약 상세 | 계약서 품목표(주문번호 연결)·버전 목록·[계약서 출력]·[수정하기] 버튼 | [자동-웹] |
| 작성중 계약: 임시저장 → 컨설팅 → 서명하기 → 계약완료 | 서명은 컨설팅 전 품목 확정 시에만 활성. 완료 시 주문 생성 + 엑셀 보관 | [자동-API] contracts.spec·vest-e2e.spec |
| 수정하기: 서명완료=서명 해제(버전 그대로) / 계약완료=사유+버전업 | 작성중 복귀, 품목·컨설팅·주문 유지 | [자동-API] |
| 취소·삭제 | 주문 생성 전에만. 취소는 종결 | [자동-API] |
| 전자서명 캔버스, 계약서 엑셀 다운로드 내용 | 서명 이미지·품목표·총액 출력 | [수동] (파일 내용 육안 확인) |

### 5-1. 베스트(3피스) — 각 단계 넣고 빼기

| 단계 | 조작 | 기대 결과 | 커버 |
|---|---|---|---|
| 작성중 | 정장 행 [베스트 포함] 체크 | "└ 베스트" 행 생성, 단가 수기, 합계 자동 반영, 옵션 화면에 베스트 탭·단계 등장 | [자동-웹] vest-web + [자동-API] vest-e2e |
| 작성중(컨설팅 확정 후) | 옵션 화면 베스트 탭 [옵션 선택 안함] | 확인 모달 → 합계 자동 차감, 베스트 행·부위·선택값 정리, 서명 게이트 유지 | [자동-웹] + [자동-API] |
| 작성중 | 베스트 재추가 | VEST 단계 선택 전까지 서명 게이트 잠김 | [자동-API] |
| 서명완료·계약완료 | 추가/제외 시도 | 409 잠금 — [수정하기]로만 | [자동-API] |
| 수정하기 후(주문 있음·미진행) | 제외 → 재서명·재완료 | 주문 VEST 구성품 취소(증분). 재추가 시 되살림 | [자동-API] |
| 제작요청 이후 | 제외 시도(옵션 화면·계약서 둘 다) | 409 차단 + 되돌리기 안내 | [자동-API] |
