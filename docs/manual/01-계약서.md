# 01. 계약서

> 모든 업무의 출발점. 계약서 **상태**가 스타일 컨설팅·채촌·작업 관리 메뉴의 사용 가능 여부를 결정합니다.
> [← 전체 흐름 보기](00-전체흐름-한장.md)

---

## 상태 흐름

```
작성중(임시저장) ──▶ 서명완료 ──▶ 계약완료
      ▲   │              │
      └───┘◀─수정하기──── ┘   (계약완료는 '수정하기'로 새 버전)
   취소 ← (작성중·서명완료에서만)
```

| 상태 | 배지색 | 의미 |
|------|:---:|------|
| **작성중** | 노랑 | 임시저장 상태. 실제 작업이 이뤄지는 단계 |
| **서명완료** | 남색 | 전자서명 완료. 컨설팅은 잠김 |
| **계약완료** | 파랑 | 주문 생성 완료. 작업 관리 시작 |
| **취소** | 빨강 | 종결 상태 |

---

## 상태별 할 수 있는 일

### 작성중
- 고객 선택 / 계약구분 선택 / 품목(맞춤·렌탈) 추가·수정
- **임시저장**
- **스타일 컨설팅** 진행 (별도 메뉴로 이동)
- **채촌** 입력 가능
- **서명하기** — 단, *컨설팅이 모두 확정돼야* 활성화
- 계약 취소 / 계약 삭제

### 서명완료
- **계약완료** 처리 → 주문 생성
- **수정하기(서명 해제)** → 작성중으로 복귀 (컨설팅 선택은 유지)
- 계약서 출력(엑셀)
- 계약 취소 (주문 생성 전이므로 가능)
- 채촌은 계속 입력 가능 / 컨설팅은 보기 전용

### 계약완료
- 계약서 출력 (완료 시점 보관본)
- **제작·입출고(작업 관리)로 이동**
- **수정하기(버전업)** → 변경사유 입력 후 새 버전 작성 (작성중으로)
- ⚠️ 이 상태에서는 직접 취소 불가 — 수정으로 새 버전을 만들어 처리

### 취소
- 계약서 출력
- 계약 삭제

---

## 주요 화면

| 화면 | 기능 |
|------|------|
| **계약 목록** | 상태·기간·계약구분 필터, 계약번호/고객명 검색, 품목 구성(정장·셔츠·구두 수량)·스타일 확정 현황 표시 |
| **계약 작성/수정** | 고객·계약구분·계약일·완료예정일 입력, 품목 편집, 하단에서 스타일 컨설팅으로 이동, 상단 [서명] |
| **계약 상세** | 상태 배지, 계약서 웹 보기, 버전 이력·변경 전후 비교, 하단 이동 버튼 |

---

## 꼭 알아둘 점

- **작성중이 핵심 작업 단계**입니다. 컨설팅·채촌은 여기서 진행하세요.
- **서명은 컨설팅 완료가 전제**입니다. 컨설팅이 안 끝나면 [서명]이 열리지 않습니다.
- **계약완료 = 주문 생성 시점**. 이때 고객이 '계약고객'으로 바뀌고, 미리 잰 채촌이 자동 연결되며, 작업 관리가 열립니다.
- **취소는 주문 생성 전(작성중·서명완료)** 에만 가능합니다.
- **맞춤(파랑)/렌탈(보라)** 태그로 거래방식이 구분됩니다.

## 수정하기 두 가지 차이

| 시작 상태 | 명칭 | 버전 | 서명 | 변경사유 |
|-----------|------|:---:|:---:|:---:|
| 서명완료 | 서명 해제 | 그대로 | 취소됨 | 불필요 |
| 계약완료 | 버전업 | +1 | 재서명 필요 | **필수** |
