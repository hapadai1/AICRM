# 02. 스타일 컨설팅

> 계약 품목마다 옵션(맞춤)이나 실물(렌탈)을 정하는 단계. **완료해야 계약서 [서명]이 열립니다.**
> [← 전체 흐름 보기](00-전체흐름-한장.md)

---

## 계약서 상태와의 관계 (가장 중요)

| 계약서 상태 | 컨설팅 편집 |
|-------------|:---:|
| **작성중** | ✅ 편집 가능 |
| **서명완료 / 계약완료** | 👁 보기 전용 (수정하려면 계약서 [수정하기]로 작성중 복귀) |

> 즉, **컨설팅은 "작성중" 계약에서만 편집**합니다. 모두 확정하면 서명 → 이후 잠깁니다.

---

## 상태별 할 수 있는 일

### 맞춤 품목
| 상태 | 표시 | 할 수 있는 일 |
|------|------|---------------|
| 미시작 | 회색 | 옵션 선택 시작, 원단·컬러·패턴·비고 입력 |
| 진행중 | 파랑 | 옵션 계속 선택·수정 |
| 확인대기 | 주황 | 확인서 보기, 다른 품목에 옵션 복사 (편집 잠김) |
| 확정 | 초록 | 확인서 보기만 (전체 잠김) |

### 렌탈 품목
| 상태 | 표시 | 할 수 있는 일 |
|------|------|---------------|
| 미시작 | 회색 | 렌탈 검색, 사이즈·컬러 지정 |
| 작성중 | 파랑 | 실물 검색·수정 |
| 확정 | 초록 | 보기만 — **서명 시 자동 확정** |

---

## 주요 기능

- **옵션 선택** — 맞춤 품목의 부위(상의·하의·베스트)별 옵션을 단계별로 선택
- **렌탈 검색** — 렌탈 실물을 검색해 부위별로 지정
- **베스트 제외** — 벌마다 베스트 포함/제외 선택 (제외 시 추가금 자동 반영)
- **동일 옵션 적용** — 같은 종류의 미확정 품목에 옵션 복사
- **원단 가격표 / 확인서 보기** — PDF·확인서 조회

---

## 진행 방법

1. 스타일 컨설팅 목록에서 고객·계약번호로 검색 → 계약 선택
2. 맞춤 품목: 부위별 옵션 선택 → 확인서 제출로 **확정**
3. 렌탈 품목: 모든 부위에 실물 지정 (서명 시 자동 확정)
4. **모든 품목 확정** → 계약서에서 [서명] 활성화

---

## 꼭 알아둘 점

- **맞춤은 명시적으로 확정**(확인서 제출), **렌탈은 서명 시 자동 확정**됩니다.
- **렌탈 전용 계약도 목록에 표시**됩니다. 계약 목록의 '스타일 확정' 열과 항상 같은 수치입니다.
- 확정 완료가 곧 **서명 가능 조건**이자 이후 **발주 전제조건**입니다.
