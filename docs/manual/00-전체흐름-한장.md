# 전체 업무 흐름 (한 장 요약)

> **계약서 → 스타일 컨설팅 → 채촌 → 작업 관리** — 네 메뉴는 계약서 상태를 축으로 유기적으로 연결됩니다.
> 앞 단계가 끝나야 다음 단계가 열리고, 하위 메뉴가 완료되면 계약서 상태가 다음으로 넘어갑니다.

---

## 핵심 원리 한 줄

**계약서 상태가 "지금 무엇을 할 수 있는지"를 결정하고, 하위 메뉴(컨설팅·채촌·발주)의 완료가 계약서 상태를 앞으로 밀어줍니다.**

---

## 계약서 상태 흐름과 메뉴 열림/닫힘

```
 ┌─────────────┐   컨설팅 완료    ┌─────────────┐   계약완료 처리   ┌─────────────┐
 │   작성중    │ ───(서명 가능)──▶ │   서명완료   │ ──(주문 생성)───▶ │   계약완료   │
 │ (임시저장)  │                  │             │                  │             │
 └─────────────┘ ◀──수정하기───── └─────────────┘ ◀──수정(새버전)── └─────────────┘
       │                                                                   │
   스타일 컨설팅 · 채촌                                                작업 관리(발주)
   (여기서 편집)                                                       (여기서 시작)
```

| 계약서 상태 | 스타일 컨설팅 | 채촌 | 작업 관리(발주) |
|-------------|:---:|:---:|:---:|
| **작성중** | ✅ 편집 | ✅ 편집 | ⛔ (주문 없음) |
| **서명완료** | 👁 보기만 | ✅ 편집 | ⛔ (주문 없음) |
| **계약완료** | 👁 보기만 | ⚠️ 연결분 잠김 / 신규는 가능 | ✅ 발주 진행 |

- ✅ 편집 · 👁 보기만 · ⛔ 사용 불가 · ⚠️ 조건부

---

## 단계별로 "무엇을 하면 다음이 열리는가"

### 1단계 — 계약서 작성 (상태: 작성중)
- 고객·계약구분·품목(맞춤/렌탈)을 입력하고 **임시저장**.
- 이 시점에 **스타일 컨설팅**과 **채촌** 메뉴가 열립니다.
- 👉 **다음으로 가는 조건:** 스타일 컨설팅을 모두 확정해야 [서명]이 열립니다.

### 2단계 — 스타일 컨설팅 (계약서: 작성중일 때만 편집)
- 맞춤 품목은 옵션을 선택해 **확정**, 렌탈 품목은 실물을 지정.
- 모든 품목이 확정되면 계약서에 **[서명]** 버튼이 활성화됩니다.
- 👉 **다음으로 가는 조건:** 서명하면 계약서가 **서명완료**로 전환됩니다.

### 3단계 — 서명 (상태: 작성중 → 서명완료)
- 서명하면 컨설팅은 **보기 전용**으로 잠깁니다(렌탈 선택은 자동 확정).
- 이 단계에서도 **채촌은 계속 입력** 가능합니다.
- 👉 **다음으로 가는 조건:** [계약완료]를 누르면 주문이 생성됩니다.

### 4단계 — 계약완료 (상태: 서명완료 → 계약완료)
- 주문(제작 대상)이 생성되고, 미리 잰 **채촌이 자동 연결**됩니다.
- 이 시점에 **작업 관리(발주)** 메뉴가 열립니다.
- 👉 **다음으로 가는 조건:** 컨설팅 확정 + 값이 든 채촌이 연결되면 [발주]가 열립니다.

### 5단계 — 작업 관리 / 발주 (상태: 계약완료)
- 품목 진행: `발주 가능 → 제작요청(발주) → 제작중 → 입고 → 출고`.
- 발주하면 그 품목의 **채촌·옵션이 고정(잠김)** 됩니다.
- 렌탈은 채촌이 없어 **컨설팅 확정 = 발주 준비 완료**.

---

## 되돌리기 (수정 흐름)

| 지금 상태 | 방법 | 결과 |
|-----------|------|------|
| 서명완료 | 계약서 [수정하기] | 작성중으로 복귀(서명만 취소, 컨설팅 유지) |
| 계약완료 | 계약서 [수정하기] | 새 버전 생성(변경사유 필수), 작성중으로 복귀 |
| 발주된 품목 | 채촌 [복사] | 새 채촌 기록 만들어 재발주 |

---

## 한눈에 보는 발주 전제조건

발주(작업 관리)가 열리려면 **아래 3가지가 모두** 충족돼야 합니다.

1. 계약서가 **계약완료** 상태 (주문 생성됨)
2. 스타일 컨설팅 **확정**
3. **값이 든 채촌**이 연결 (빈 채촌은 인정되지 않음 → 발주 막힘)

> ⚠️ **자주 겪는 실수:** 채촌을 값 없이 저장하면 목록엔 "완료"처럼 보여도 발주가 막힙니다. 반드시 치수를 입력해 저장하세요.
