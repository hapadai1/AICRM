# 04. 작업 관리 (발주 · 제작 진행)

> 계약완료된 주문을 공장에 발주하고 제작 진행을 관리. **계약완료 이후에 열립니다.**
> [← 전체 흐름 보기](00-전체흐름-한장.md)

---

## 언제 열리나

계약서가 **계약완료**되어 주문이 생성되면 이 메뉴가 활성화됩니다.
발주 [발주] 버튼은 **아래 3가지가 모두 충족**될 때만 열립니다.

1. 계약서 **계약완료**
2. 스타일 컨설팅 **확정**
3. **값이 든 채촌** 연결 (맞춤 품목)

---

## 품목 진행 흐름

```
발주 가능 ─▶ 제작요청(발주) ─▶ 제작중 ─▶ 입고 ─▶ 출고
```

- **맞춤 트랙:** 제작 발주 → 가봉 입고 → 가봉 피팅 → 완성복 입고 → 완성복 출고
- **렌탈 트랙:** 렌탈 수선 요청 → 수선 입고 → 렌탈 출고 → 렌탈 반납

---

## 상태별 할 수 있는 일

| 품목 상태 | 할 수 있는 일 |
|-----------|---------------|
| 옵션/채촌 대기 | 발주 불가 — 컨설팅·채촌 먼저 완료 |
| **발주 가능** | [발주] → 발주 팝업에서 작업지시서 확인 후 발주 |
| **제작요청(발주 후)** | 서류 보기, 최종본 파일 업로드·삭제 (채촌·옵션 변경 불가) |

---

## 발주 팝업에서 할 수 있는 일

- 스타일 컨설팅 확정 상태·연결 채촌 확인
- **다른 완료 채촌으로 교체** (발주 전만 가능)
- 작업지시서 미리보기 · 출력 · 인쇄
- 최종본(수기 파일) 업로드 · 다운로드 · 삭제
- [발주하기] → 작업지시서 발행 + 상태 전환이 동시에 처리

---

## 준비 카드 (한눈에 보는 준비 상태)

계약 1건당 하나의 준비 카드로 표시:

| 항목 | 완료 조건 |
|------|-----------|
| 계약 | 계약완료 (고정) |
| 스타일 컨설팅 | 품목 확정 |
| 채촌 | 값 든 채촌 연결 (맞춤만, 렌탈은 해당 없음) |

---

## 꼭 알아둘 점

- **발주하면 그 품목의 채촌·옵션이 고정(잠김)** 됩니다. 공장 작업이 시작되기 때문입니다.
- **빈 채촌은 발주를 막습니다.** "완료된 채촌이 있어야 발주할 수 있습니다" 메시지가 뜨면 채촌 값을 입력하세요.
- **렌탈은 컨설팅 확정 = 준비 완료** (채촌 불필요).
- 이미 발주한 품목의 팝업은 '서류 보기' 모드로만 열립니다 (재출력 없음, 최종본 관리만).
