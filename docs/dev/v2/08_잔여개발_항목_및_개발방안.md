## 0. 결론 — "왜 메뉴마다 계속 나오는가"

v2 요건 자체는 **대부분 구현 완료**다. 계속 새 항목이 나오는 이유는 미구현이 남아서가 아니라, 잔여분이 아래 **4가지 성격**으로 흩어져 있고 그중 **B(현업 결정 대기)가 24건**으로 가장 많기 때문이다. 화면을 하나씩 볼 때마다 그 화면에 걸린 미결 1~2건이 새로 보이는 구조다.

| 유형 | 건수 | 성격 | 끝내는 방법 |
|---|---|---|---|
| **A. 실제 결함·잔재** | 3 | 코드가 요건과 어긋남 | ✅ **완료(R1, 2026-07-28)** |
| **B. 현업 결정 대기(미결사항)** | 24 | 설계서에 ⚠️로 남긴 정책 질문 | ✅ **전건 확정(2026-07-28)** — 21건은 현행 확정, 5건이 개발로 전환 |
| **C. 요건 미충족(양식 실측 대기)** | 2 | 엑셀 셀 좌표를 몰라 보류 | ✅ **완료(R3, 2026-07-28)** — 템플릿 실측으로 해소 |
| **D. 외부 산출물·연동 대기** | 4 | 벤더/양식 수령 전엔 불가 | 교체 지점만 확정, 대기 |
| **E. 인수·배포** | 3 | 수동 시연·운영 구성 | 배포·백업 구성 ✅ 완료 / 수동 시연 2건 남음 |

**B를 닫는 것이 이 문제의 실질적 해답이었고, 2026-07-28 현업 확인으로 전건 확정됐다.**
확정 내용은 각 설계서(01~06)의 '미결사항' 절에 반영했다. 이제 메뉴를 다시 훑어도 새 미결 항목은 나오지 않는다.

> **진행 경과(2026-07-28)**
> - ✅ R1 잔재 제거 · R3 양식 실측 반영 · Q-3 배포·백업 구성
> - ✅ R2 결정 세션 — 미결 24건 전건 확정(21건 현행 확정 / 5건 개발 전환)
> - ✅ S1 소품 묶음 — 단계 완료 확인창, 연락 재발송 안내, 가봉 첨부 라벨 정정, 설계서 미결란 폐쇄
> - ✅ S2 계약금·잔액 제거 — `deposit_amount`·`balance_amount`·`balance_due_date` 삭제, 총액만 유지
> - ⏭ 남은 개발: **S3 계약 흐름·계약서 보관** → **S4 렌탈 대여일 필수**
> - ⏸ 대기: D(외부 연동 4건, 현재 착수 불가) · Q-1·Q-2(현업 수동 시연)

## 3. 현업 결정 결과 (2026-07-28 확정)

미결 24건 + 고객모드 2건을 전건 확정했다. 상세는 각 설계서의 '미결사항' 절.

### 3.1 현행 그대로 확정 — 개발 없음 (21건)

| 영역 | 확정 내용 |
|---|---|
| 진행상태 | 초도상담은 **진행단계가 아니다**(예약의 한 종류) · 상담 예약은 날짜가 지나면 종료, 배치 없음 · 수선 1건 = 진행 1건 · 건너뛰기는 **현재 단계만 검증** |
| 고객·계약 | 나이는 **정수 직접입력** · 서명 시점 총액 스냅샷 **불필요**(순서로 해결, 3.2-②) · 서명 멱등 헤더 미적용 · 서명 이미지 규격 현행 |
| 컨설팅·렌탈 | 사이즈는 **호수 체계**(90~120) · 기존 SKU 컬러/사이즈 free 문자 **그대로** · 베스트 전용 칸 **신설 안 함** · 옵션 그룹 대표 이미지 **두지 않음** · `fabricName` 존치 · 렌탈은 **날짜 단위**(오전/오후 없음) |
| 채촌·제작 | 완성(센치) 열은 **비워 둠** · 앞마다/뒷마다 용어 확정 · inch **소수 1자리** · 작업지시서 출력 후 **사진 추가 허용**(버전 안 올림 — 치수를 새로 잡으면 그때 새 버전) · 구두 시트 구성 현행(옵션 전량 + 메모 + 신체 + 신발 사이즈) · 셔츠 전용 양식 도입 안 함 |
| 고객모드 | 유휴 **5분** · 재인증은 **현재 로그인 사용자만** · 검색 결과는 이름 + 마스킹 전화 · 재인증 **1회성** · 단일 탭 전제 |

### 3.2 개발로 전환된 결정 (5건)

| # | 확정 내용 | 작업 |
|---|---|---|
| ① | **연락 중복** — 이미 journey 단일 경로로 일원화돼 있고 발송하면 버튼이 사라진다. 별도 DB 불필요 | ✅ S1-W2: 되돌렸다 재전진해 이미 나간 건은 "이미 발송되어 다시 보내지 않았습니다" 안내 |
| ② | **계약 흐름** — 스타일 컨설팅 완료 → [서명하기] 활성 → [계약 완료] 활성. `COMPLETED` 상태 신설. 변경계약하면 서명이 풀리고 재서명·재완료 | S3-W5 |
| ③ | **계약금·잔액 제거** — 전부 일시불이라 관리하지 않는다. 컬럼째 삭제, **총액만 유지** | ✅ S2-W4 |
| ④ | **계약서 엑셀 보관** — [계약 완료] 시점에 구워서 보관, 이후 다운로드는 보관본 | S3-W6 |
| ⑤ | **렌탈 대여일 필수** — 대여 시작·반납일을 받아 그 기간으로 가용 재고 검색 | S4-W7 |
| ⑥ | **단계 완료** — 마지막 품목을 완료하면 단계 완료 **확인창**을 띄운다(자동 전진 아님). 되돌리기는 품목·단계 모두 기존 기능 사용 | ✅ S1-W1 |
| ⑦ | **가봉 첨부** — 공장에 **보낸** 작업지시서 보관용(파싱 없음). `FACTORY_SENT` / '공장 발송본' | ✅ S1-W3 |
