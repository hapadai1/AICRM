## 0. 결론 — "왜 메뉴마다 계속 나오는가"

v2 요건 자체는 **대부분 구현 완료**다. 계속 새 항목이 나오는 이유는 미구현이 남아서가 아니라, 잔여분이 아래 **4가지 성격**으로 흩어져 있고 그중 **B(현업 결정 대기)가 24건**으로 가장 많기 때문이다. 화면을 하나씩 볼 때마다 그 화면에 걸린 미결 1~2건이 새로 보이는 구조다.

| 유형 | 건수 | 성격 | 끝내는 방법 |
|---|---|---|---|
| **A. 실제 결함·잔재** | 3 | 코드가 요건과 어긋남 | ✅ **완료(R1, 2026-07-28)** |
| **B. 현업 결정 대기(미결사항)** | 24 | 설계서에 ⚠️로 남긴 정책 질문 | **1회 확인 세션으로 일괄 확정** ← 핵심 |
| **C. 요건 미충족(양식 실측 대기)** | 2 | 엑셀 셀 좌표를 몰라 보류 | ✅ **완료(R3, 2026-07-28)** — 템플릿 실측으로 해소 |
| **D. 외부 산출물·연동 대기** | 4 | 벤더/양식 수령 전엔 불가 | 교체 지점만 확정, 대기 |
| **E. 인수·배포** | 3 | 수동 시연·운영 구성 | 배포·백업 구성 ✅ 완료 / 수동 시연 2건 남음 |

**B를 한 번에 닫지 않는 한 "메뉴별로 뭐가 계속 나오는" 현상은 반복된다.** 3장의 결정 체크리스트가 이 문제의 실질적 해답이다.

> **진행 경과(2026-07-28)** — R1(잔재 제거)·R3(양식 실측 반영)·Q-3(배포·백업 구성) 완료.
> 남은 것은 **B(현업 결정 24건)** · **D(외부 연동 4건, 현재 착수 불가)** · **Q-1·Q-2(수동 시연)**뿐이며,
> 셋 다 코드가 아니라 **결정·외부 산출물·현업 시연**을 기다리는 항목이다.

## 3. 현업 결정 체크리스트 (R2에서 한 번에 확정)

> 이 24개만 답하면 잔여 개발 범위가 확정되고, 이후 메뉴를 다시 훑어도 새 항목이 나오지 않는다.

**진행상태** ① 초도상담 단계 제거? ② 예약일 경과 자동종료 배치 필요? ③ 수선 journey = 요청 1건 단위? ④ 완성복 입고 연락은 journey로 일원화? ⑤ 단계 건너뛰기 시 중간 게이팅 강제? ⑥ 전진 후 이전 단계 완료 취소 허용?

**고객·계약** ⑦ 나이는 직접입력 유지? ⑧ 서명 시점 총액 고정 필요? ⑨ 엑셀에 계약금/잔액도? ⑩ 계약서 엑셀 파일 보관 필요? ⑪ 서명 이미지 크기 규격? ⑫ 잔금일 입력칸 부활?

**컨설팅·렌탈** ⑬ 렌탈 가용검색 기준일? ⑭ 기존 SKU 컬러/사이즈 코드 정규화 범위? ⑮ 사이즈 호수 체계로 확정? ⑯ 베스트 전용 지시서 칸 신설? ⑰ 부위 대표 이미지 필요? ⑱ 렌탈 시간 단위(오전/오후) 필요?

**채촌·제작** ⑲ 완성(센치) 열(U열, "cm" 라벨 인쇄됨)에 넣을 값? ⑳ 앞마다/뒷마다 용어 확정? ㉑ inch 소수 자리수? ㉒ 출력 후 사진 추가 허용? ㉓ 가봉 업로드 = 보관용? 파싱 반영? ㉔ 구두 지시서 포함 항목?

**고객모드**(추가 확인) 유휴 타임아웃 분, 타 관리자 대신 재인증 허용 여부.
