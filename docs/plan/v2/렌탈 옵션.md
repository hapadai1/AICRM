# 렌탈 품목·컬러·사이즈 (현업 확정 2026-07-29)

렌탈 실물은 **구분 + 컬러 + 사이즈**로만 식별한다. 디자인 축은 폐기했다.
컬러·사이즈는 품목마다 쓰는 코드가 달라 기준정보에 `componentTypes`(적용 품목)를 함께 둔다.

## 렌탈 품목 (5종)

정장상의(JACKET) · 정장하의(TROUSERS) · 베스트(VEST) · 셔츠(SHIRT) · 구두(SHOES)

## 정장 컬러 (12색)

"3피스 / 2피스 / 상의"는 색 이름이 아니라 **그 색으로 몇 벌이 있는지**다.
3피스 = 상의·하의·베스트, 2피스 = 상의·하의(베스트 없음), 상의 = 자켓만.
그래서 코드·이름에는 넣지 않고 **적용 품목(componentTypes)** 으로만 표현한다 — 코드는 색 그 자체다.

## 생성된 재고 (566건)

정장 3종은 **컬러 × 사이즈 조합마다 3벌**, 셔츠·구두는 1벌씩 보유한다.

| 품목 | 컬러 | 사이즈 | 조합(SKU) | 조합당 보유 | 실물 |
|---|---|---|---|---|---|
| 정장상의 | 12색 전부 | 7 | 84 | 3 | **252** |
| 정장하의 | 8색 (3피스 6 + 2피스 2) | 7 | 56 | 3 | **168** |
| 베스트 | 6색 (3피스만) | 7 | 42 | 3 | **126** |
| 셔츠 | 1색 | 6 | 6 | 1 | **6** |
| 구두 | 2색 | 7 | 14 | 1 | **14** |
| | | | 202 | | **566** |

관리코드는 `{접두어}-{컬러}-{사이즈}-{연번}` (JKT / TRS / VST / SHT / SHO).
같은 조합을 여러 벌 보유하므로 연번으로 가른다.
예: `JKT-BLACK-46-001` · `-002` · `-003`, `TRS-NAVY-92-001`, `SHO-SHOE_BROWN-270-001`

셔츠·구두의 `SHIRT_`/`SHOE_` 접두어는 남긴다 — 개수가 아니라 **어느 품목의 색인지**를 가르는
구분이고, 코드가 전역 유일이라 화이트·블랙·브라운이 정장 색과 겹치기 때문이다.
