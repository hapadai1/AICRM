

* 고객용 UI : 고객 모드

1. 모드변경
- 고객 모드 / 관리자 모드 > 버튼은 왼쪽 메뉴 맨 하단에 구분 버튼을 넣어서 메뉴 모드를 변경한다.
- 관리자 모드변경 선택시 : 관리자 화면 전환시 비번 입력을 한번 더 받는다. > 비밀번호

2. 고객 모드 대상 메뉴 4개 신규로 생성 : 고객, 계약관리, 스타일 컨설팅, 채촌
 - 다른 고객 리스트는 안보이고, 해당 고객의 정보만 출력되어야 한다.
 - 메뉴 이동 : 위의 4개 메뉴는 고개모드 - 고객에서 검색한 고객 1명의 정보만 출력한다.
 - 방안 : 별로 메뉴로 만들어서, 고객 모드/ 관리자 모드 에 따라서 각각의 메뉴가 출력되도록 한다.
 
3.고객모드
- 전체 flow :
  고객 등록
   > 계약서 작성 : 비즈니스 구분(비즈니스 정장, 웨딩패키지), 품목 수정
   > 스타일 컨설팅
   > 계약서 : 최종확인 (추가 옵션가격등) > 서명하기 > 엑셀 출력
   > 채촌
- 화면간 이동 : 계약서 작성시 등록한 사용자 정보를 가지고 화면마다 이동 버튼으로 이동한다.


4. 고객모드 메뉴
 0) 고객 메뉴
    (1) default 최초 화면
    - 고객 검색 필드만 뜬다.
      -- 고객명을 입력하고 검색하면 등록된 고객이 있으면
         .고객의 진행 중인 고객 정보 "계약서, 컨설팅 스타일, 채촌": 진행상태와 기본정보를 출력하고 선택하면 각각 내용으로 이동한다.

      -- 고객이 없으면 고객 등록 화면 뜬다.
         .예약 고객 중 정보를 가져와서 고객 등록 화면에 데이터를 출력한다. 예약 고객도 정보도 없으면 최초 등록 화면 출력한다. > [고객 등록] 버튼 선택 > 고객 등록 완료되면 "계약서" 등록 화면 이동

 1) 계약서 등록 화면 :
     - [고객 등록] 버튼 선택시 > 계약서 화면이 뜬다.
     - 고객만 등록 되어있어도
          고객 정보 "계약서, 컨설팅 스타일, 채촌": 진행상태와 기본정보를 출력하고 선택하면 각각 내용으로 이동한다.
             > 계약서 선택하면 계약성 작성 화면 이동
             > 계약서 등록 완료되면 하단에 "스타일 컨설팅" 버튼 눌러서 이동

 2) 스타일 컨설팅
      - 계약 고객의 품목이 첫화면에 뜬다.
      - 옵션등 작업을 한다.

 3) 채촌
      - 계약 고객의 채촌 등록 화면이 뜬다.

* 예약
- 시간 단위 : 1시간 (현재 30분을 1시간으로 변경)
- (완료기능) 예약 고객만 출력됨
- (추후) 네이버 연동 : 수동, 자동


* 고객
- 고객정보 등록 필드 추가 : 키, 체중, 나이 > 엑셀 작업지시서 추가
- 기능
   . 검색조건 - 전체 상태검색 : 진행중/완료/전체 보기 버튼
   . 검색조건 - 진행상태 검색 : 상태 버튼들 (검색용) - 상태 정의 다시하고, 상태별 검색 기능
   . 검색결과 리스트 - 고객상태 열 : 현재 "진행 상태"를 출력 해야함 (asis : 계약 코드만 출력되는데, 세부 상태를 출력함)




* 계약서
- 계약서 서명 기능 : -모두 작성하고 나서 > [서명하기 버튼] > 서명하기 단계
                               -계약서 폼에 서명까지 저장
- 엑셀 계약서 출력 기능
- 계약서 품목명 - 정장, 셔츠, 구두, 옵션

- 웹화면 출력 :
   최초 : 품목 개수 가격 > 상세
   스타일 옵션 추가시 : 옵션명, 가격 > 상세
  
- 엑셀 계약서 출력 : 품목 : 세부 품목, 개수는 출력
                               가격 : 품목 세부 가격은 제외, 전체 가격만 출력



* 스타일 컨설팅
- (완료) 확인서 : 완료 확인할때. 옵션 선택한 것만 출력한다.
- (완료) 양복 2번이어도 각각 옵션을 선택한다.

- ex)  맞춤
 정장1
   - 상의 : 원단, 컬러, 옵션 정장 상의
   - 하의 : 원단, 컬러, 옵션 정장 하의
   - 베스트 : 원단, 컬러, 옵션 정장 베스트  -  스티치, 카라
 정장2
   - 상의 : 원단, 컬러, 옵션 정장 상의
   - 하의 : 원단, 컬러, 옵션 정장 하의
   - 베스트 : 원단, 컬러, 옵션 정장 베스트  -  스티치, 카라

- 각 필드
  . 원단 : 수기 입력
  . 컬러 : 수기 입력
  . 패턴 : 수기 입력
  > 각 내용 엑셀 작업지시서 인티그레이션


- ex)  렌탈
   
 정장1
  - 상의 :  컬러, 사이즈 , 비고 > 렌탈 품목 지정
  - 하의 :  컬러, 사이즈 , 비고 > 렌탈 품목 지정
  - 베스트 : 컬러, 사이즈 , 비고 > 렌탈 품목 지정
  
- 각 필드
   . 컬러 : 12가지 (다운리스트 코드 선택)
   . 사이즈 : (다운리스트 코드 선택)
   . 비고 : 수선 명령 수기 입력 (수치 등)



* 제작관리
  - 구두 : 옵션 추가, 작업지시서 > 그냥 메모 처럼 출력
  - 제작요청 완료는 수기로 체크 : 엑셀 다운로드시 자동 완료 기능 제외
  - 가봉 작업지시서 : 엑셀 업로드 기능




* 채촌
이미지 업로드
 - 개수 설정은 , 최데 50장을 넘지는 않는다.
 - 업로드 버튼 위치 : 기능 버튼 위치
 - 업로드 이미지 출력 위치 : 제일 하단

이미지 출려 기능
 - 출력 이미지 개수 지정 ( 체크박스 or 전체 드래그)
 - 선택된 개수만큼 A4 한장에 출력됨

- 전체 치수 변환 버트 : cm, inch 전환 버튼
- 엑셀 작업지시서 : 신체 열에 cm 출력, 완성(인치) : inch 변환해서 출력
- 채촌 추가 필드
   앞마다
   뒷마다
    > 엑셀 작업지시서 : 하의 추가요청사항 : 앞, 뒤 매핑 출력
