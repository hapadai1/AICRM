# 상태·버튼 정리 (2026-07-31 구현 기준, 참조용)

계약서·컨설팅·주문·채촌의 최종 상태값과 화면 버튼. 정본 설계는 `계약흐름_상태설계_0731.md`.

핵심 규칙:
> 수정하기 = 품목 추가 전용 (물리화된 품목 감소 불가)
> 취소·삭제 = 주문 생성 전에만. 취소는 종결(수정하기 없음)
> 컨설팅 편집 = 계약 작성중 + 품목 미진행. 채촌 = 언제든 수정

---

## 1. 계약서

### 상태 (Contract.status)

| 코드 | 라벨 | 의미 |
|---|---|---|
| DRAFT | 작성중 | 초안 또는 수정하기로 되돌린 상태 |
| SIGNED | 서명완료 | 서명 받음, 계약완료 대기 |
| COMPLETED | 계약완료 | 계약 성립 — 주문 생성, 이행 시작 |
| CANCELLED | 취소 | 종결 (복구 없음) |

전이: `작성중 →(서명하기) 서명완료 →(계약완료) 계약완료 →(수정하기·버전업) 작성중 → …`
서명완료 →(수정하기·서명 해제, 버전 그대로) 작성중. 취소는 작성중·서명완료 + **주문 없음**에서만.

### 상태별 가능 작업

| 상태 | 계약서 수정 | 컨설팅 | 주문 | 취소 | 삭제 |
|---|---|---|---|---|---|
| 작성중 (주문 없음) | ○ | ○ | 없음 | ○ | ○ |
| 서명완료 (주문 없음) | ✕ | ✕(보기만) | 없음 | ○ | ✕ |
| 계약완료 | ✕ | ✕(보기만) | 생성·진행 | ✕ | ✕ |
| 작성중 (수정하기 후, 주문 있음) | **품목 추가만** | 미진행 품목만 | 진행 계속 | ✕ | ✕ |
| 취소 | — | — | — | — | ○ |

### 버튼

**계약 작성 화면(CONT-002, `/contracts/new?contractId=`)** — 작성중 전용
| 버튼 | 노출·활성 조건 | 동작 |
|---|---|---|
| 임시저장 | 항상 | 초안 저장 (물리화 품목 수량 감소 시 409 거부) |
| 서명하기 | 컨설팅 전 품목 확정 시 활성 | 서명 캔버스 → 서명완료로 |
| 계약 취소 | **주문 없을 때만 노출** (flow.canCancel) | 사유 모달 → 취소(종결) |

**계약 상세 화면(CONT-003, `/contracts/:id`)** — 헤더 우상단
| 버튼 | 노출 조건 | 동작 |
|---|---|---|
| 계약서 출력 | 항상 | 엑셀 다운로드 (완료 후엔 보관본) |
| 계약완료 | 서명완료 | 확인 → 주문 물리화 + 엑셀 보관 |
| **수정하기** | 서명완료 | 확인 → 서명 해제, 작성중 복귀(버전 그대로) → 작성 화면 |
| **수정하기** | 계약완료 | 사유 모달 → 버전업, 작성중 복귀 → 작성 화면 |
| 계약 취소 | 작성중·서명완료 + 주문 없음 | 사유 모달 → 취소(종결) |
| 계약 삭제 | 임시저장·취소 + 주문 없음 | 확인 → 물리 삭제 |

두 [수정하기]는 같은 라벨·같은 위치 — 버전업 여부는 시스템만 관리.

## 2. 컨설팅 (스타일 컨설팅 = 맞춤 옵션 + 렌탈 선택)

### 상태 (OptionSelectionSession.status — 진행률 표시용)

| 코드 | 라벨 | 색 |
|---|---|---|
| NOT_STARTED | 미시작 | default |
| IN_PROGRESS | 진행중 | blue |
| REVIEW | 확인대기 | orange |
| CONFIRMED | 확정 | green |

전이: `미시작 →(단계 저장) 진행중 →(전 단계 완료) 확인대기 →(최종 저장) 확정`
확정 →(옵션 변경) 새 선택 버전 — **계약 작성중 + 품목 미진행일 때만**.

### 잠금 규칙 (서버 가드 + 화면 동시 적용)

편집 가능 = **계약 작성중(DRAFT) AND 품목 미진행(주문품목이 없거나 CREATED)**.
그 외엔 보기 전용. 차단 메시지: "작성중인 계약에서만 …" / "제작 진행 중인 품목은 … 되돌린 뒤 진행해 주세요."

### 버튼

**계약 옵션 화면(`/contracts/:id/options`)**
| 버튼 | 조건 | 동작 |
|---|---|---|
| 원단 가격표 (헤더) | 항상 | PDF 모달 |
| 옵션 선택 / 옵션 보기 (행) | 편집 가능하면 [옵션 선택](primary), 확정·잠금·제작중이면 [옵션 보기](눈 아이콘) | 옵션 팝업 |
| 실물 검색 (렌탈 행) | 계약 작성중일 때만 활성 | 렌탈 실물 팝업 |
| 확인서 보기 (행) | 확인대기·확정 또는 전 단계 완료 | 확인서 이동 |
| ⋯ 동일 옵션 적용 | 계약 작성중 + 대상(같은 카테고리·미확정·미진행) 존재 | 옵션 복사 |
| 인라인 입력(원단·컬러 등) | 편집 가능할 때만, 아니면 읽기 전용 | blur 시 자동 저장 |
| (배너) | 잠긴 계약이면 "보기 전용" 안내 배너 표시 | — |

**옵션 팝업/페이지(`/options/:itemId`)**: 선택 시작 · 이전 · 다음/완료 · 중단(미확정) · {부위} 저장(페이지) · 옵션 변경(확정 + 편집 가능 시에만)
**확인서(`/options/:itemId/review`)**: 최종 저장(확정)(미확정 + 편집 가능) · 옵션 변경(확정 + 편집 가능) · 계약금액 반영(차액 있음 + 편집 가능) · 단계 카드 클릭=해당 단계 이동

## 3. 주문 (제작·입고/출고)

**주문에는 자체 취소가 없다** — 상태 전이에서 취소 직접 진입을 서버가 거부. 취소는 계약 취소(주문 전)뿐.
계약과의 접점: ①계약완료 시 생성 ②재계약완료 시 추가 품목만 증분 반영. 계약이 작성중으로 되돌아가도 제작·입출고는 계속.

### 상태

**주문 헤더 (Order.status)**: `CREATED` 생성 / `CANCELLED` 취소 — 2개만 표시. 진행은 품목이 담당.

**주문 품목 (OrderItem.status)** — PDF 단계와 1:1:
```
생성 → 옵션 대기 → 채촌 대기 → 발주 가능(미주문) → 제작 요청 → 제작중
→ 가봉 입고 → 가봉 완료 → 제작 완료 → 부분 입고 → 입고 완료 → 부분 출고 → 출고 → 완료
```
순방향·건너뛰기 허용, 역행은 사유 필수, 취소 직접 진입 불가. 부분 입고/출고는 구성품 집계 전용.

**구성품 (OrderItemComponent.status)**: `생성 → 제작요청 → 제작중 → 가봉입고 → 제작완료 → 입고 → 출고`, 렌탈 `예약 → 입고 → 출고`.

### 버튼

**주문 상세(`/orders/:id`)** — 상태 변경 버튼 없음(전부 이동·추가)
| 버튼 | 조건 | 동작 |
|---|---|---|
| 계약 상세 (헤더) | 항상 | 이동 |
| 옵션 진행 · 채촌 · 작업지시서 (품목 카드) | 맞춤 + 미취소 | 각 화면 이동 |
| 구성품 추가 | 미취소 + ORDER_EDIT | 생성 모달 |
| 렌탈 배정 (구성품 행) | 렌탈 + RENTAL_ALLOCATE | 배정 화면 이동 |

**계약별 제작 관리(`/contracts/:id/production`)** — 상태를 바꾸는 유일한 화면
| 버튼 | 조건 | 동작 |
|---|---|---|
| 출력/재출력 · 보기 · Excel (작업지시서) | 옵션 확정 + 채촌 완료 시 활성 | 작업지시서 |
| 제작요청 완료 (품목) | 제작 요청 이전 상태 + PRODUCTION_EDIT | 품목 → 제작 요청 |
| 가봉 기록 (품목) | FITTING_EDIT | 가봉 모달 |
| 다음 할 일 (구성품) | 상태별 동사형: 제작요청→제작시작→가봉입고/제작완료→입고→출고 | 전이 (입고·출고는 날짜 모달) |
| ⋯ 건너뛰기·되돌리기 | 예외 경로 있을 때 | 건너뛰기 즉시 / 역행은 사유 필수. **취소 항목 없음** |

## 4. 채촌

### 상태 (completedAt 유무로 파생)

| 코드 | 라벨 | 의미 |
|---|---|---|
| DRAFT | 작성중 | 입력 중 |
| COMPLETED | 완료 | 작업지시서에 쓸 수 있음 — **수정을 막지 않음** |
| (locked) | 잠금 | 작업지시서 출력에 사용됨 — 수정·삭제·완료해제 차단 (사진 첨부만 허용) |

규칙: **언제든 수정, 저장하면 반영. 수정은 버전을 만들지 않고, 회차(V1, V2…)는 [신규 채촌] 등록 시에만 증가.** 잠긴 채촌을 고치려면 새로 등록.

전이: `등록 → 작성중 →(완료, 값 1개 이상) 완료 ↔(완료 해제) 작성중`, `완료 →(작업지시서 출력) 잠금`

### 버튼

**목록(`/measurements`)**: 신규 채촌(툴바, MEASUREMENT_EDIT) · 행별 기록 보기 / 채촌 · 검색 + 전체/미완료/완료 세그먼트

**등록·편집(`/measurements/:id`)**
| 버튼 | 조건 | 동작 |
|---|---|---|
| 등록 | 신규 + 고객 선택 | 세션 생성(회차 증가) |
| **저장** | **잠금만 아니면 항상 (완료 후에도 가능)** | 값 반영, 완료본은 감사로그 '완료 후 수정' |
| 완료 | 미완료 + 값 1개 이상 | 완료 처리 |
| 완료 해제 | 완료 + 미잠금 | 완료 표시 되돌리기 |
| 삭제 | 잠금만 아니면 | 확인 후 삭제 |
| 이전 버전과 비교 | 이전 회차 존재 | 비교 화면 |
| 사진 업로드(50장) · 선택 인쇄 | 기존 세션 (잠금이어도 첨부 가능) | 업로드 / A4 인쇄 |
| cm·인치 전환 · 버전 Select · 숫자 키패드 | — | 표시·입력 |
